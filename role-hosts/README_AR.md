# برامج استضافة واختبار NOVA وفراس كلكل
هذه أدوات أندرويد خفيفة مبنية على WebView النظام، وليست استضافة لخادم أو قاعدة بيانات. لا تغيّر شيئًا في الخوادم.

- NOVA: ستة أبواب مستقلة (مدير تجريبي، جرسون أول وثانٍ، مطبخ، بوفيه، محاسب). يضغط التطبيق على بطاقة الدخول التجريبي تلقائيًا. الخادم: https://nova-neon-field-demo.onrender.com/
- فراس كلكل: المالك والزبون، لكل منهما بيانات دخول محفوظة في جلسة منفصلة على الهاتف. الخادم: https://fras-ordr.onrender.com/ . لا يختلق التطبيق كلمة مرور للمالك أو الزبون.

**عزل الأدوار:** لكل Activity عملية Android خاصة بها وتستخدم `WebView.setDataDirectorySuffix` قبل تهيئة WebView، لذلك لا تتعارض ملفات تعريف الارتباط والجلسات ولا يقوم تغيير الدور بتسجيل خروج الدور الآخر.

**الحماية:** حسابات NOVA التجريبية للديمو فقط ولا تُستخدم لإدخال بيانات مالية حقيقية. يجب إيقاف `PILOT_QUICK_LOGIN` قبل الاعتماد التجاري، مع تغيير الأسرار المكشوفة.

**التركيب:** حمّل الملفين من GitHub Actions في الفرع `test-hosts-nova-firas`، ثم ثبّت `nova-debug.apk` و`firas-debug.apk`. يمكن تثبيتهما معًا بسبب اختلاف معرف الحزمة.
